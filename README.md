# Cross Edge Dash — Xbox 360 English Translation

An English translation project for **Cross Edge Dash** on **Xbox 360**, using the official English PlayStation 3 localization for the original content shared with Cross Edge.

> **Current status: Private Beta testing in progress.**

## About the Project

The original Cross Edge received an official English localization on PlayStation 3. Cross Edge Dash, released exclusively in Japan for Xbox 360, includes additional content and did not receive an official English release.

The goal of this project is to bring the existing official English localization to the Xbox 360 version rather than retranslate content that already has an official English equivalent.

## Translation Approach

The project distinguishes between two types of content:

- **Content shared with the original Cross Edge:** uses the official English PS3 localization.
- **Additional Japanese content exclusive to Cross Edge Dash:** receives a separate English translation using AI assistance.

The additional material requires identification, translation, editing and integration into the Xbox 360 version. The aim is to preserve the terminology and style of the official localization wherever possible.

## Xbox 360-Exclusive Content

Cross Edge Dash includes additional material beyond the original PS3 release, including:

- A Coliseum mode featuring 50 battles.
- Exclusive Coliseum encounters.
- Additional event CG illustrations.
- Xbox 360 achievements.
- Additional costume forms and downloadable content.

Some downloadable content was distributed separately and may not be included in the base game.

## Technical Work

Porting an existing localization between PlayStation 3 and Xbox 360 requires more than copying text. The game resources and technical implementation differ between platforms.

The project involves adapting and integrating the official translated content, identifying Xbox 360-exclusive Japanese material, and checking that text and events display correctly during gameplay.

## Current Progress

## Beta Testing

Invited testers are helping check the game in real gameplay conditions.

Useful testing areas include:

- Main story progression and dialogue.
- Events and character interactions.
- Menus, character information and interface text.
- Battles, items and equipment.
- The exclusive Coliseum mode.
- Xbox 360-specific content.
- Remaining Japanese text.
- Translation consistency and terminology.
- Text overflow, alignment and graphical issues.
- Crashes, freezes or broken events.
